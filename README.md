## Overview

Soundtoys Devil-Loc models a rare vintage hardware limiter known for its extremely aggressive, program-dependent compression and harmonic distortion at extreme settings.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Soundtoys Devil-Loc** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Squash Mode** | Extreme program-dependent limiting with heavy harmonic saturation |
| **Crush Mode** | Additional bit-crush mode for even more aggressive lo-fi character |
| **Clip Control** | Adjustable output clip level for creative limiting |
| **Mix Knob** | Wet/dry blend integrates extreme compression in parallel |
